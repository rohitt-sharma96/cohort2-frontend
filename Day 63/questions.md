### Scenario 1: Weather Dashboard with Error Handling

- Build a small weather dashboard that fetches current weather data from  any public weather API (such as. OpenWeatherMap.)

- You must make the API request asynchronously using fetch with async/await

- If the API request fail (for example, due to an invalid city name), you must handle the error using try-catch.

- Additionally, create and throw custorm error based on weather conditions.

- For Example:
    If the temperature is high or extremely low, throw a custom error and handle it properly in your code.
